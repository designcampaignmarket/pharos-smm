# Pharos Global — SMM monitoring

Парсер по ТЗ SMM Pharos Global: собирает заголовок, ссылку, дату, источник и краткое описание из 13 источников ТЗ и формирует очередь для редактора. Полные тексты и изображения не сохраняются, ничего не публикуется автоматически.

## Что получается в `output/`

| Файл | Что это |
| --- | --- |
| `digest.md` | Новое за запуск (🆕) и всё за 7 дней по рубрикам Insights |
| `queue.csv` | Кандидаты за 14 дней в колонках листа «Очередь» — вставить в таблицу |
| `news.json` | Все собранные элементы (до 1000) |
| `errors.md` | Источники, которые не ответили или закрыты robots.txt → ручная проверка |
| `state.json` | Что уже видели и когда опрашивали каждый источник |

## Режим опроса

- RSS (ФРС, ЕЦБ) — каждые 2–4 часа.
- Обычные страницы — по `min_hours` в `sources.json`: приоритет А раз в 12 ч, Б — раз в 2–7 дней.
- Перед каждым сайтом проверяется robots.txt. Если он запрещает доступ или не читается, источник уходит в `errors.md`, обхода нет.
- Дубли убираются по каноническому URL (без utm-меток) и по заголовку.
- У IEA и BIS включён фильтр по ключевым словам ТЗ (`keywords`), у остальных берётся всё.

## Установка

1. Создать репозиторий (например `pharos-smm`) и загрузить все файлы, включая `.github/workflows/parse.yml`.
2. Settings → Actions → General → Workflow permissions → **Read and write**.
3. Actions → Pharos monitoring → **Run workflow** (галочка «Опросить все источники сразу» для первого запуска).
4. Дальше запускается сам каждые 4 часа.

Локально: `pip install -r requirements.txt && python parser.py --force`.

## Google Alerts

В `sources.json` → `google_alerts` есть две заготовки (FSC Mauritius, ESMA). Создайте алерт на google.com/alerts с доставкой «RSS feed», вставьте адрес ленты в `url` — источник подключится сам.

## Как добавить источник

Строка в `sources`: `type` = `rss` или `html`; для `html` в `link_contains` указать фрагменты адресов новостей на странице — так парсер берёт только нужные ссылки.
